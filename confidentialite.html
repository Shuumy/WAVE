Confidentialité

WAVE est une application web de musique publiée par Shuumy sur GitHub Pages. Cette page décrit ce que fait la version web. Coordonnées de l’éditeur à compléter avant publication.

Bibliothèque locale

Les fichiers audio importés, leurs métadonnées, tes playlists, favoris, notes et préférences sont enregistrés dans le stockage local de ton navigateur (IndexedDB). Ils ne sont pas envoyés au serveur WAVE lors de leur importation. Supprimer les données du site depuis Safari efface cette bibliothèque. Le navigateur peut également libérer son stockage ; garde une copie de tes fichiers.

Recherche et services externes

Quand tu recherches une musique, les termes saisis sont transmis au service de recherche WAVE hébergé chez Render, qui interroge YouTube Music. Les résultats peuvent contenir des images chargées depuis des serveurs tiers. La lecture d’un résultat peut charger le lecteur YouTube ; l’ouverture d’un lien YouTube te fait quitter WAVE. L’extraction des métadonnées de tes fichiers utilise une bibliothèque chargée depuis cdnjs uniquement au moment de l’import ; les fichiers restent traités dans ton navigateur.

Cookies et mesure d’audience

Le code WAVE ne place pas de cookie de suivi et ne comprend pas d’outil de mesure d’audience. Les services tiers ouverts ou chargés à ta demande disposent de leurs propres règles et peuvent utiliser des traceurs. Consulte leurs politiques respectives. Aucun bandeau de consentement WAVE n’est affiché tant qu’aucun traceur non nécessaire n’est installé par WAVE.

Hébergement et droits

GitHub Pages et Render peuvent traiter des données techniques liées aux requêtes, comme l’adresse IP, selon leurs propres politiques. WAVE ne dispose pas de compte utilisateur pour synchroniser ta bibliothèque. Tu peux effacer les données locales dans les réglages de Safari. Pour toute question concernant les données traitées par l’éditeur, un contact privé doit être ajouté avant publication ; ne publie aucune donnée personnelle dans une issue GitHub.
